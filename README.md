## Overview

CoreArchCoverage provides a comprehensive **architectural coverage framework** for RISC-V verification. It enables verification engineers to measure and track coverage of RISC-V ISA features (both privileged and unprivileged) by running lightweight simulation.

### Salient Features
- Supports standalone runs (without RTL) or integration into a co-simulation environment
- Supports autogenerated coverage model while allowing users to write targeted coverage
- Allows use of all SystemVerilog Coverage features for user-written coverage 
- Helps to measure stimulus quality early in the Testbench development cycle 

The framework consists of two main components:

1. **Coverage Generation** - Queries whisper and generates coverage artifacts as SystemVerilog Package
2. **Coverage Sampling** - Runtime sampling and recording of coverage data

### Coverage Generation
The `cov_gen` module queries whisper, an open source ISS, and generates SystemVerilog package called **cp_pkg.sv**. 
The information is represented as:
- Enums
- Attributes (Standalone variables)
- Instruction Classes
- CSR classes

The cp_pkg can be imported into user-written coverage model to re-use the autogenerated artifacts. 

### Coverage Sampling  
The `cov_sample` module is a C++ and SV testbench which runs a test (ELF) and samples coverage data from whisper. 
The information is sampled at the end of an instruction boundary (at retirement). The sampled information is sent by whisper to the SV testbench using DPI interface. 
The SV testbench formats the information for consumption by the coverage model and records the coverage by calling `sample()` on the covergroups. 

## Getting Started

### Requirements 
Following are the dependencies for running the framework:
- `Riscv GCC Toolchain` - [riscv-gnu-toolchain GitHub](https://github.com/riscv-collab/riscv-gnu-toolchain)
- `whisper` - [whisper GitHub](https://github.com/tenstorrent/whisper)
  - Refer to **Requirements** section of whisper for more information.
- `magic_enum` - [Magic Enum Github](https://github.com/Neargye/magic_enum)


### Quick Start
- Clone the project
```
git clone https://github.com/tenstorrent/corearchcoverage.git
```

- Pull the submodules
```
git clone https://github.com/tenstorrent/corearchcoverage.git
```
- Build Whisper:
```
cd whisper 
make BOOST_DIR=<path_to_your_boost_libraries> SOFT_FLOAT=1 MEM_CALLBACKS=1 TRACE_READER=0 
```
- Build cov-gen module
```
cd cov_gen
make BOOST_DIR=<path_to_your_boost_libraries>
```
- Run the generated cov-gen module from the `build` directory
```
./cov_gen <path_to_whisper_configuration_json> cp_pkg.sv
```
